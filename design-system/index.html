Layout rules

  • Content width: 76rem maximum.
  • Reading width: 65 characters.
  • Control height: 44px minimum.
  • Card padding: 24–32px.
  • Section spacing: 48px on small screens, 72–96px on large screens.
  • Use logical properties for right-to-left layouts.

Disclosure

What should a project brief include?
Include the decision to support, audience, markets, timing and expected deliverables. Identify open questions rather than inventing precision.
How should a limitation be presented?
Place it beside the finding it qualifies. Distinguish reported experiences from prevalence and statistical estimates.

07

Readable by design.

The supplied text, action and status color pairs are checked programmatically. This is evidence for these tokens, not a blanket accessibility certification for every page that uses them.

  • Normal text contrast: at least 4.5:1.
  • Interactive boundaries: at least 3:1 against their surface.
  • Visible keyboard focus and 44px controls.
  • Native labels, errors and status messages.
  • No essential meaning communicated by color alone.
  • Reduced motion and right-to-left layout support.
