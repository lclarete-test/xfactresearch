# XFact Research

Website for XFact Research.

Static HTML, CSS, JavaScript and assets, published with GitHub Pages.

## Design system

The [XFact design system](design-system/README.md) includes brand foundations, design tokens, reusable components, accessible light and dark themes, and research patterns.

Open the [visual component guide](design-system/index.html) through a static HTTP server or the site's `/design-system/` route after GitHub Pages deploys it. [Color contrast results](design-system/contrast-report.json) and an [accessibility checklist](design-system/ACCESSIBILITY.md) are included.

Technical setup and deployment notes: [deployment README](docs/deployment/README.md).
